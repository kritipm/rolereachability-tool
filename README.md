# Emerging Roles · Reachability

Live tool that scores how reachable emerging PM-adjacent roles are for candidates based on their actual background.

## What it does

Takes a candidate's education, skills, experience level, and communication fit and runs them through a rule-based scoring engine across 18 emerging roles. Returns a tiered result — high reachability, reachable, or stretch — with role-specific gap analysis and AI-generated explanations for each score. Candidates can mark roles they want to pursue. A passcode-gated KPI dashboard tracks whether 35% of unique testers mark at least one role reachable — the core product KR.

## Stack

React · Vite · Claude API · Upstash Redis · Vercel Serverless

## Built as

A PM-led build — product decisions, architecture, spec, and iteration owned end to end. AI-assisted development used throughout to ship faster without compromising on thinking depth or decision quality.
